# DreamSentinel Telegram Mini-App Bot

L'écosystème DreamSentinel AI intègre un bot Telegram natif pour offrir une expérience mobile-first aux traders de la communauté Somnia.

## Fonctionnalités

1. **Web App (Mini-App) Intégrée** : Permet aux utilisateurs d'ouvrir l'interface React Next.js complète directement à l'intérieur de Telegram.
2. **Notifications Push** : Alertes d'arbitrage croisé (Arbitrage Scanner) envoyées directement sur Telegram.
3. **Copilote IA par Chat** : Possibilité d'interroger le moteur IA (Sentinel-Macro) par des messages Telegram standards.
4. **Duels PvP 60s** : Notifications de défis pour rejoindre l'arène instantanément via smartphone.

## Lancement

```bash
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN="votre_token_botfather"
python bot.py
```

*Note: Pour les besoins du Hackathon, le bot est en mode Mock pour démontrer la faisabilité technique de l'intégration Omni-channel de DreamSentinel.*
